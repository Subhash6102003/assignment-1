# LaunchPulse GTM Studio: Production Cloud Deployment Guide

**Target Cloud Infrastructure:**
* **Frontend:** [Vercel](https://vercel.com) (React 19 + Tailwind v4 Single-Page Application)
* **Backend:** [Railway](https://railway.app) or [AWS EC2](https://aws.amazon.com/ec2/) (FastAPI + Uvicorn)
* **Database & Artifact Storage:** PostgreSQL / Persistent SQLite + Disk/S3 Export Archive (Stores all products, campaigns, pricing tiers, generated PDFs, and historical telemetry)
* **AI Engine:** Claude Desktop via Model Context Protocol (MCP stdio over HTTP)

---

## 1. Frontend Deployment on Vercel

The frontend is a Vite + React 19 application. Pre-configured with [`vercel.json`](file:///d:/don't_know/Assignment%201/frontend/vercel.json).

### Step-by-Step Vercel Setup:
1. **Push your repository** to GitHub (or GitLab).
2. Go to [vercel.com](https://vercel.com) and click **"Add New Project"**.
3. Import your repository and configure the project settings:
   * **Root Directory:** Click *Edit* and select `frontend` (or `Assignment 1/frontend` depending on repository root).
   * **Framework Preset:** `Vite` (Auto-detected).
   * **Build Command:** `pnpm build` (or `npm run build`).
   * **Output Directory:** `dist`.
4. **Environment Variables:**
   Under **Environment Variables**, add:
   * **Key:** `VITE_API_URL`
   * **Value:** The URL of your deployed Railway or AWS EC2 backend  
     *(e.g., `https://launchpulse-backend.up.railway.app` or `http://your-ec2-ip`)*.
5. Click **Deploy**. Vercel will build and assign you a global domain like `https://launchpulse.vercel.app`.

## 2. Backend Deployment on Railway (Easiest Cloud Setup)

Railway provides instant container hosting with zero server configuration and automatic PostgreSQL database provisioning.

### Step-by-Step Railway Setup:
1. Go to [railway.app](https://railway.app) and click **"New Project"**.
2. Select **"Deploy from GitHub repo"** and choose your repository.
3. In **Settings**:
   * Set **Root Directory** to `backend` (or `Assignment 1/backend`).
   * Railway automatically detects the [`Dockerfile`](file:///d:/don't_know/Assignment%201/backend/Dockerfile) or [`Procfile`](file:///d:/don't_know/Assignment%201/backend/Procfile).
4. **Attach a Persistent Database:**
   * Inside your Railway project canvas, click **"New" $\rightarrow$ "Database" $\rightarrow$ "Add PostgreSQL"**.
   * Railway automatically injects the `DATABASE_URL` environment variable into your backend service!
5. **Attach Volume for Generated PDFs:**
   * In your backend service settings, add a **Volume** mounted at `/app/exports`. All generated executive GTM PDFs will persist permanently.
6. **Generate Public Domain:**
   * Go to **Settings $\rightarrow$ Networking $\rightarrow$ Generate Domain** *(e.g., `https://launchpulse-api-production.up.railway.app`)*.
7. Copy this URL and set it as `VITE_API_URL` in your Vercel project settings.

## 3. Backend Deployment on AWS EC2

For dedicated enterprise infrastructure using AWS.

### Step-by-Step EC2 Setup:
1. **Launch EC2 Instance:**
   * **AMI:** Ubuntu Server 22.04 LTS or 24.04 LTS (x86_64).
   * **Instance Type:** `t3.small` or `t3.micro` (1 vCPU, 1–2 GB RAM).
   * **Storage:** 20 GB gp3 EBS (persistent storage for SQLite database and generated PDF archives).
   * **Security Group:** Open inbound ports:
     * `22` (SSH from your IP)
     * `80` (HTTP from anywhere)
     * `443` (HTTPS from anywhere)
2. **Connect via SSH:**
   ```bash
   ssh -i your-key.pem ubuntu@your-ec2-public-ip
   ```
3. **Clone Repository & Run Automated Setup:**
   ```bash
   git clone https://github.com/your-username/launchpulse.git
   cd launchpulse/"Assignment 1"/backend
   chmod +x deploy_ec2.sh
   ./deploy_ec2.sh
   ```
   *The script automatically installs system dependencies, sets up the Python virtual environment, initializes the database, configures the `launchpulse.service` systemd daemon, and sets up Nginx as a high-performance reverse proxy.*
4. **Attach Custom Domain & Free SSL (Let's Encrypt):**
   ```bash
   sudo certbot --nginx -d api.yourdomain.com
   ```
5. Check backend status:
   ```bash
   sudo systemctl status launchpulse
   curl http://localhost:8000/api/products
   ```

## 4. Database Architecture & PDF Storage

The database layer handles persistence across restarts:

### A. Dual Database Support (PostgreSQL + SQLite)
* **Local Development & EC2:** Runs on persistent SQLite (`launchpulse.db`) stored on disk or EBS.
* **Railway & Cloud RDS:** Automatically switches to **PostgreSQL** when `DATABASE_URL` is set:
  ```env
  DATABASE_URL=postgresql://postgres:password@roundhouse.railway.app:5432/railway
  ```

### B. Generated PDFs & Report Archive
Every strategic dossier generated by Claude or the user can be compiled into a branded executive PDF:
* **Generation Engine:** Built with `reportlab` inside [`backend/pdf_generator.py`](file:///d:/don't_know/Assignment%201/backend/pdf_generator.py).
* **Storage Table:** The `gtm_pdf_exports` table records every generated PDF:
  ```sql
  CREATE TABLE gtm_pdf_exports (
      id INTEGER PRIMARY KEY AUTOINCREMENT,
      product_id INTEGER NOT NULL,
      report_id INTEGER NOT NULL,
      filename TEXT NOT NULL,
      file_path TEXT NOT NULL,
      file_size_bytes INTEGER DEFAULT 0,
      created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP
  );
  ```
* **PDF Download Endpoint:**
  * `GET /api/reports/{id}/export-pdf` $\rightarrow$ Generates and streams executive PDF binary (`application/pdf`) with page numbers, margin breakdown, pricing tables, and strategic roadmap.
  * In the frontend Report view, users can click **"Download PDF Dossier"** or the top **"Export PDF"** button.

## 5. Connecting Claude Desktop MCP to Remote Backend

Once your backend is live on Railway or AWS EC2, you can connect your local Claude Desktop to it over the internet!

Edit your `claude_desktop_config.json`:
* **Windows:** `%APPDATA%\Claude\claude_desktop_config.json`
* **macOS:** `~/Library/Application Support/Claude/claude_desktop_config.json`

```json
{
  "mcpServers": {
    "launchpulse-gtm": {
      "command": "python",
      "args": [
        "d:/don't_know/Assignment 1/mcp-server/server.py"
      ],
      "env": {
        "LAUNCHPULSE_API_URL": "https://launchpulse-backend.up.railway.app"
      }
    }
  }
}
```

Now, whenever you chat with Claude Desktop on your computer:
1. Claude calls `create_gtm_product` or `implement_gtm_strategy`.
2. The MCP server calls your live **Railway / AWS EC2 API**.
3. Your **Vercel frontend** updates live anywhere in the world!
